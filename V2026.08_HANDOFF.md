## 📁 Files Created/Modified

### New Scripts Created
1. **`scripts/ingest_amp_collection.py`**
   - Ingests AMP CDEs from RoP-compatible CSV format
   - Maps "AMP" → "AMP (SysBio FAIRplex)"
   - Handles JSON metadata fields
   - Output: `data/amp/staging/amp_cdes.parquet`

2. **`scripts/merge_amp_with_foundation.py`**
   - Merges v2026.04 with AMP collection
   - Handles schema alignment (metadata_variants, alternate_codes)
   - Output: `data/final/v2026.08_elements.parquet`

3. **`scripts/embed_amp_incremental.py`**
   - Generates SapBERT embeddings for 535 AMP CDEs
   - Uses GPU acceleration (CUDA)
   - Appends to existing v2026.04 embeddings
   - Output: `data/final/v2026.08_embeddings.npy`

4. **`scripts/build_v2026_08_faiss.py`**
   - Rebuilds IVF4096 FAISS index for 1,329,508 vectors
   - Training time: ~23 min, Total: ~26 min
   - Output: `data/final/v2026.08_embeddings.faiss`

5. **`scripts/package_v2026_08_bundle.py`**
   - Packages final bundle with manifest
   - Calculates SHA256 checksums
   - Output: `dist/rop_v2026.08/`

### Modified Files
1. **`rop/schema.py`** (line 42)
   - Added: `AMP_SYSBIO = "AMP (SysBio FAIRplex)"`

```bash
# Check FAISS installation
python3 -c "import faiss; print(f'FAISS version: {faiss.__version__}')"

# Re-run build (takes ~26 min)
python3 scripts/build_v2026_08_faiss.py
```

### To verify bundle integrity:
```bash
# Check file sizes
ls -lh dist/rop_v2026.08/

# Verify checksums
cd dist/rop_v2026.08/
sha256sum -c <(python3 -c "import json; m=json.load(open('manifest.json')); [print(f\"{v['sha256']}  {k}\") for k,v in m['files'].items()]")
```
